# Overview

![Kizashi Banner](./assets/banner.png)

**Kizashi** is a modern Wayland desktop shell designed to be aesthetic, performant, and effortless to use. Originally created by ilyamiro after his `nixos-configuration` project gained popularity, it has evolved into a dedicated desktop shell.

## Compositor configuration

Kizashi is only a desktop shell. It does not manage keybinds or monitors.

Compositor guides:

- [Hyprland](./configure/compositors/hyprland.md)
